llama.cpp 算子之旅

一个视角：一个算子，从模型定义出发，如何落到 CPU / GPU / NPU 上真正执行。 这套课件逐层拆解它在 ggml 里怎么被表示、怎么从模型定义被建造成一张图、 怎么被调度器切给不同后端、最后在 CUDA / Vulkan / Metal / SYCL / CANN / Hexagon / OpenVINO 等后端上变成真实的 kernel。
